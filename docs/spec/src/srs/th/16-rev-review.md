# โมดูลทบทวนและวิเคราะห์ {#rev}

## วัตถุประสงค์และขอบเขต {#rev-purpose}

โมดูลทบทวนและวิเคราะห์เป็นส่วนของ Fisko ที่มองข้ามโมดูลอื่น ให้ผู้ใช้ทุกคนเห็นตัวเลขสำคัญที่หน้าแรก ให้ผู้บริหารเห็นภาพการใช้จ่ายภาพเดียว ให้คะแนนโครงการ ชี้การใช้จ่ายที่ควรตรวจ และเก็บสิ่งที่ฟีเจอร์ AI ของทุกโมดูลใช้ร่วมกัน ได้แก่ กติกาของผู้ช่วย กรอบงานเอเจนต์ และการกำกับดูแล AI

โมดูลนี้อ่านข้อมูล ไม่ได้ทำงานแทนโมดูลอื่น โมดูลนี้เป็นเจ้าของเฉพาะระเบียนของตน ได้แก่ รายการผิดปกติ วาระ คะแนน และค่าตั้ง และไม่เปลี่ยนระเบียนของโมดูลอื่น ข้อเสนอใด ๆ ต้องผ่านการทำงานปกติของโมดูลเจ้าของเสมอ ขณะนี้ยังไม่มีโค้ด production บทนี้จึงอ่านจากโค้ดต้นแบบและการทดสอบ sweep

พฤติกรรม AI ทุกอย่างในต้นแบบเป็นการจำลอง ไม่มีการเรียกโมเดล คำตอบหรือขั้นตอนของเอเจนต์เกิดจากกฎหรือแม่แบบตายตัวที่ทำงานบนข้อมูลตัวอย่าง ADR-0016 กำกับผลิตภัณฑ์จริง ได้แก่ AI ปิดเป็นค่าเริ่มต้น ทุกฟีเจอร์ทำงานได้โดยไม่มี AI gateway ลบข้อมูลส่วนบุคคลก่อนส่ง และคนเป็นผู้ตัดสินใจทุกครั้ง แถวในบทนี้ที่กล่าวถึง AI คือข้อกำหนดของพฤติกรรมใน production และสถานะบอกเพียงว่าการจำลองแสดงพฤติกรรมนั้นได้เพียงใด

| องค์ประกอบ | สถานะในต้นแบบ | หลักฐาน |
| --- | --- | --- |
| การ์ดหน้าแรก | สร้างแล้ว | sweep เปิดหน้าเท่านั้น |
| แดชบอร์ดผู้บริหาร | สร้างแล้วบนข้อมูลจัดสรรและการจ่ายจริงในระบบ | sweep เปิดหน้าเท่านั้น การตรวจปีปัจจุบันสนับสนุน BGT-FR-133 |
| บัตรคะแนนโครงการ | สร้างแล้ว | sweep เปิดหน้าเท่านั้น |
| รายการผิดปกติของการใช้จ่าย | มีการคัดกรองบนรายการตั้งต้น ยังไม่มีการตรวจจับ | sweep เปิดหน้าและแสดง drawer เท่านั้น |
| มุมมอง KPI พยากรณ์ และสัญญาณข้ามโมดูล | ยังไม่สร้าง แต่ละโมดูลมีหน้าของตน | ไม่มี |
| วาระข้ามโมดูล | ยังไม่สร้าง วาระเดียวในโค้ดคือวาระคณะกรรมการงบประมาณ | ไม่มี |
| ผู้ช่วยร่วม | กฎและข้อมูลตัวอย่าง ไม่มีการเรียกโมเดล | ชุด chat ตรวจเฉพาะข้อความ |
| กรอบงานเอเจนต์ | เครื่องจำลองแยกกันสามชุด ไม่มีการเรียกโมเดล | sweep เริ่มเอเจนต์ Budget และ Finance แต่ไม่เริ่มเอเจนต์ Procurement |
| การกำกับดูแล AI | สร้างแล้ว ด้วยค่าตัวอย่างและค่าตั้งต้น | sweep เปิดหน้าเท่านั้น |

## ผู้เกี่ยวข้อง {#rev-actors}

| ผู้เกี่ยวข้อง | บทบาทในโมดูลทบทวนและวิเคราะห์ | บทบาทในต้นแบบ |
| --- | --- | --- |
| ผู้บริหาร | อ่านแดชบอร์ดและบัตรคะแนน ถามผู้ช่วย เริ่มเอเจนต์ และในต้นแบบเปิดปิดเอเจนต์และตั้งระดับ | `exec` |
| เจ้าหน้าที่กองแผนงาน | อ่านแดชบอร์ด บัตรคะแนน และรายการผิดปกติ เริ่มเอเจนต์งบประมาณ ตัดสินขั้นที่เขียนข้อมูล | `plan` |
| เจ้าหน้าที่การเงิน | อ่านแดชบอร์ดและรายการผิดปกติ เริ่มเอเจนต์การเงิน รับรายการผิดปกติที่ส่งตรวจเพิ่ม | `fin`, `finhead` |
| ผู้ตรวจสอบ | ตัดสินรายการผิดปกติ อ่านเอเจนต์ การทำงาน และบันทึกการใช้ AI | `audit` |
| เจ้าหน้าที่หน่วยงาน | เห็นการ์ดหน้าแรกและแดชบอร์ด ถามผู้ช่วย | `div`, `divhead` |
| เจ้าหน้าที่พัสดุ | เห็นการ์ดหน้าแรกและแดชบอร์ด เริ่มเอเจนต์จัดซื้อ | `proc`, `prochead` |
| ผู้ดูแลระบบ | เลือกเปิดใช้ AI ให้หน่วยงาน (XC-AI-002) ต้นแบบไม่มีหน้าของบทบาทนี้ในโมดูลนี้ | `admin` |
| เอเจนต์ AI | ทำขั้นตอนจากทะเบียนเครื่องมือและหยุดรอคน ทะเบียนเอเจนต์อยู่ในหัวข้อกรอบงานเอเจนต์ | ฟังก์ชันกฎ |
| งานอัตโนมัติของระบบ | ตรวจจับรายการผิดปกติและปรับปรุงมุมมอง ต้นแบบยังไม่มี | ไม่มี |
| ผู้ให้บริการโมเดล (ภายนอก) | ให้บริการผ่าน gateway แก่หน่วยงานที่เลือกเปิดใช้ | จำลอง ไม่มีการเรียก |

# ข้อกำหนดร่วม {#xc}

ทุกโมดูลต้องเป็นไปตามทุกแถวในบทนี้ และบทของโมดูลไม่กล่าวซ้ำ บทของโมดูลเพิ่มแถวเฉพาะเรื่องที่เป็นของโมดูลนั้น ฟีเจอร์แพลตฟอร์มที่รองรับกฎเหล่านี้ เช่น หน้าจอการตรวจสอบหรือขั้นตอนจัดการเหตุละเมิด อยู่ในบท[แพลตฟอร์ม](#plt)

ต้นแบบทำงานบนเบราว์เซอร์อย่างเดียว ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล และไม่มีการเข้าสู่ระบบจริง แถวส่วนใหญ่จึงเป็น Planned แถวที่เป็น Prototyped คือแถวที่ต้นแบบมีพฤติกรรมนั้นและ `tests/sweep.js` ตรวจไว้เท่านั้น ตัวเลขที่ระบุว่าเป็นค่าที่เสนอไม่ได้มาจากข้อกฎหมาย ADR หรือโค้ด เจ้าของผลิตภัณฑ์ต้องยืนยัน

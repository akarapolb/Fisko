# ภาคผนวก {#appendices}

ภาคผนวกนี้รวบรวมสิ่งที่บทต่าง ๆ ยังเปิดไว้ ได้แก่ การตัดสินใจที่ยังต้องการ จุดที่การออกแบบต่างจากโค้ด ข้อบกพร่องที่พบในต้นแบบ และระดับการตอบทะเบียนข้อกฎหมาย

## ประเด็นเปิดจำแนกตามผู้ตัดสิน {#app-open}

ประเด็นเปิด 112 รายการจากบทข้อกำหนดร่วมและบทโมดูลแสดงไว้ที่นี่ตามผู้ที่ต้องดำเนินการ ประเด็นที่มีผู้ตัดสินหลายรายอยู่ใต้ผู้ที่ระบุเป็นรายแรก และคอลัมน์ที่สามแสดงทุกราย ข้อความคัดจากบทต่าง ๆ ดังนั้นคำว่า "บทนี้" ในแถวหมายถึงบทของโมดูลเจ้าของประเด็น

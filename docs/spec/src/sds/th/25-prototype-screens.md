# หน้าจอจากต้นแบบ {#screens}

บทนี้แสดงหน้าของต้นแบบแยกตามโมดูล เพื่อให้ผู้อ่านการออกแบบหาพฤติกรรมต้นทางได้ หน้าเหล่านี้ไม่ใช่หน้าจอของระบบจริง แต่ใช้แสดงพฤติกรรม ส่วนหน้าจอของระบบจริงเป็นไปตาม ADR-0004

> [!OPEN] บทนี้ไม่มีภาพหน้าจอ เจ้าของผลิตภัณฑ์ต้องตัดสินว่าจะฝังภาพหน้าจอหรือไม่ เพราะภาพจะทำให้เอกสารใหญ่ขึ้น และต้องจับภาพใหม่ทุกครั้งที่ต้นแบบเปลี่ยน

## วิธีกำหนดหน้า {#scr-nav}

อาร์เรย์ `NAV` ใน `src/js/00-core.js` เก็บรายการหน้า โดย `src/js/20-shell.js`, `64-duties.js`, `71-t2.js`, `90-systems.js` และ `95-projects.js` เพิ่มรายการเข้าไป ส่วน `BUD_PAGES` ใน `75-budget-pages.js`, `PROC_PAGES` ใน `74-proc-pages.js` และ `FIN_PAGES` ใน `66h-fin-pages.js` กำหนดรหัสและหน้าของทั้งสามแอป

route ของหน้าคือ hash ของ URL เช่น `#requests` ส่วน Procurement และ Finance มี route เดียวคือ `#procurement` และ `#finance` และใช้ลิงก์ `prc-<page>` และ `fnc-<page>` เลือกหน้าภายในผ่าน `jump()` พอร์ทัลผู้ขายใช้ `vp-<tab>` ในลักษณะเดียวกัน แท็บผู้ดูแลระบบมี route ของตนเองคือ `#admin-<tab>` รายการบทบาทอยู่ที่แต่ละหน้า หน้าจึงแสดงเฉพาะบทบาทที่ระบุ

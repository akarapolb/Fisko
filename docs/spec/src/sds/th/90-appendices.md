# ภาคผนวก {#appendices}

ภาคผนวกนี้รวบรวมประเด็นการออกแบบที่ยังเปิด การตัดสินใจด้านสถาปัตยกรรมที่เอกสารนี้ใช้ และข้อกฎหมายที่การออกแบบตอบ

## ประเด็นการออกแบบที่ยังเปิด {#app-dg}

บทต่าง ๆ มีประเด็นการออกแบบ 77 รายการ แต่ละแถวคัดจากบทที่ตั้งประเด็น และแสดงสิ่งที่การออกแบบสมมติไว้จนกว่าจะมีการตัดสิน ประเด็นที่ยกมาจาก SRS ยังใช้รหัส OI และอยู่ในดัชนีที่ภาคผนวกของ SRS

| งบประมาณ | 9 | [งบประมาณ](#bgt-open) |
| จัดซื้อจัดจ้าง | 12 | [จัดซื้อจัดจ้าง](#prc-open) |
